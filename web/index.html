TANKSIM

Локальная арена для танковых программ на Python. Загрузите свой скрипт, выберите противника и карту — бой рассчитается целиком, без пауз, и сохранится реплей, который можно пересмотреть по кадрам.

Формат программы TANKP

Файл с расширением .tankp.py. Первая строка — заголовок версии, дальше необязательные метаданные в комментариях:

#!TANKP 1
# name: Мой танк
# author: Я
# difficulty: 3
# color: #42a5f5
# description: Что умеет.
# tags: скорость,тактика

from tankp import TankProgram, Action


class Brain(TankProgram):
    """Мозг танка. Вызывается 60 раз в секунду."""

    def on_start(self, ctx):
        self.память = 0

    def on_tick(self, o):
        self.память += 1
        if o.enemy is None:
            turn, drive = o.steer_to(*o.map.spawns[1 - o.tank])
            return Action(drive=0.8, turn=turn)

        # враг виден только в радиусе обзора и если нет стены между нами
        err = o.me.turret_error(o.lead(o.enemy))
        return Action(drive=0.4, turn=o.sign(o.me.hull_error(o.enemy)),
                      turret=o.sign(err), fire=abs(err) < 5)


program = Brain()

Несколько файлов: zip

Если боец не помещается в один файл — рядом с кодом нужны веса, настройки или свои модули — соберите zip. Точка входа — main.py строго в корне архива, остальное кладётся рядом и доступно обычным import и open относительно __file__:

мой-танк.zip
├── main.py            ← #!TANKP и program = Brain()
├── brain.py           ← import brain
├── weights.json       ← open('weights.json') рядом с main.py
└── cfg.yaml

Имя архива становится именем бойца. Служебные каталоги (__pycache__) и бинарники при распаковке пропускаются, а имена вроде engine или tankp на верхнем уровне запрещены: пакет не должен подменять модули движка.

Что доступно программе

ОбъектЧто внутри
o.meсвой танк: x, y, hull, turret, vx, vy, hp, hp_max, ammo_ready, cooldown, reload
o.enemyпротивник, если он в поле зрения, иначе None
o.tankиндекс своего танка: 0 или 1
o.tick, o.timeномер тика и время в секундах
o.mapкарта: rows, clearance, blocked_at/blocked_between, steer_to, spawns
o.lead(enemy)точка встречи с летящим снарядом
o.log(...)строка в журнал боя

Правила честной игры

  • Один тик — один вызов on_tick. Не успеваешь за бюджет — команда считается пустой.
  • Видно только то, что видит танк: и линия прямой видимости.
  • Завис или съел память — процесс перезапускается, нарушение попадает в журнал.
  • Программа не может писать файлы и выходить в сеть: она работает в отдельном процессе.

Броня

На урон броня не влияет: пробитие всегда стоит одного и того же урона. Единственное, что она делает, — рикошет. Угол считается между направлением удара и нормалью грани: чем он больше, тем выше шанс скользнуть. Лоб держит удар дольше всех (отскакивает при угле к нормали > 45°), а борт и корма рикошетят при угле к нормали > 60°.
